# StepSmart – Career Clarity Dashboard

📊 Project Overview

**StepSmart – Career Clarity Dashboard** is an interactive Power BI dashboard designed to help students explore suitable **degrees, colleges, career opportunities, and salary ranges** based on their academic background and performance.

The project brings student, degree, college, and career information together into a single interactive dashboard for easier analysis and decision-making.

---

🎯 Objectives

- Analyze student academic performance and school groups.
- Explore available degree options and their demand levels.
- Analyze and compare colleges based on relevant information.
- Explore career opportunities associated with different degrees.
- Analyze salary ranges for different career roles.
- Provide an interactive recommendation dashboard based on student inputs.

---

 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Microsoft Excel** – Dataset preparation and storage
- **Power BI Data Modeling** – Relationships between datasets



📁 Dataset

The project uses structured datasets containing information related to:

- Students
- School Groups
- Degrees
- Colleges
- Careers
- Salary Ranges
- Demand Levels
- College Ratings
- College Types
- Locations

The data was prepared and cleaned before being integrated into Power BI.



🔄 Data Preparation Process

The data preparation process was completed in four major stages:

 1. Data Collection
Relevant student, degree, college, and career data were collected and organized.

 2. Data Cleaning
Duplicate records, missing values, inconsistent entries, and formatting issues were checked and corrected.

 3. Data Transformation
Data types were standardized and required fields, calculations, and measures were prepared for analysis.

 4. Data Modeling
Relationships were established between the datasets to enable interactive filtering and analysis across the dashboard.

The dashboard uses Power BI interactive features such as:
